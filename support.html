JofolL隐私说明

读得顺手，从这里开始。

导入书籍、漫画和图片

在书库右上角点击“＋”，选择“导入文件”或“导入图片文件夹”。如果文件位于 iCloud Drive 或其他文件服务，先在“文件”App 中下载到设备，再导入。JofolL 会复制文件到当前书库，不删除原文件。

电子书支持 EPUB、PDF、UTF-8 / UTF-16 与可识别中文编码的 TXT。漫画压缩包支持 ZIP / CBZ、RAR / CBR、7z / CB7、TAR / CBT；压缩包内应包含可解码的图片，图片按文件名自然排序。JPEG、PNG、WebP、HEIC、TIFF 等图片也可导入，具体解码能力取决于系统和文件本身。

遇到无法读取的文件

DRM 保护的电子书、密码保护的 PDF、加密或分卷压缩包暂不支持。GIF / APNG 显示静态帧；特殊图片、RAW 格式及损坏文件可能无法读取。请保留原文件，并记录提示、格式、设备型号与系统版本，联系支持。不要在邮件中附上私密或无权分享的书籍。

调整翻页和背景

阅读时点击中央显示控制栏，从右上角“更多 → 阅读设置”选择翻页方式、单页或双页、阅读方向、背景及文字大小。每本书可以使用自己的设置。横向阅读时，可将支持的漫画或 PDF 设置为双页。

整理书库与隐私阅读

左上角“目录”内可查看阅读状态和分组，并切换普通或隐私书库。右上角“整理书库”内可按最近阅读、导入时间、名称、文件大小、进度或手动顺序排列。选择书籍后，可复制或移动到另一书库；复制保留两边独立的阅读记录。

隐私书库使用设备的 Face ID、Touch ID 或密码进行身份验证。请先为设备设置密码。切到后台后会重新锁定。隐私书库不纳入 App 自动备份，请保留自己的原文件。隐私模式不能阻止他人拍摄屏幕，也不能代替设备安全。

标注与笔记

阅读时从“更多”创建手写标注或文字笔记，并在“标注与笔记”中查看。文字书的手写笔记保留当时的页面快照，字号改变后不会将笔迹错误覆盖到新排版上。

Support in English

Import your own files with the + button. Download cloud files to the device first. Supported common formats include EPUB, PDF, TXT, ZIP/CBZ, RAR/CBR, 7z/CB7, TAR/CBT and common images. DRM, encrypted/split archives and password-protected PDFs are not supported. The initial app interface is in Simplified Chinese.

Reading options are in the reader’s More menu. The top-left directory button opens groups, reading status and private-library access. The private library uses device authentication, locks when backgrounded, and is excluded from automatic app backup. Keep your source files. Please email the address above with your device, OS, format and exact error. Do not send private or copyrighted material without permission.
